# SDL2 Lessons — C

Практический курс по разработке игр на C и SDL2.

Цель этой части курса — познакомиться с языком C и библиотекой SDL2 на практике, постепенно двигаясь от простого окна до полноценной 2D-игры.

Курс ориентирован на начинающих разработчиков и показывает, как устроен игровой цикл и базовые системы игры без использования готового игрового движка.

🎯 Что вы изучите

В процессе прохождения уроков вы познакомитесь с:

* языком C;
* SDL2;
* созданием окна;
* игровым циклом;
* обработкой событий;
* клавиатурным вводом;
* рендерингом;
* текстурами;
* отображением текста;
* временем и delta time;
* структурами и перечислениями C;
* организацией игрового кода;
* базовой игровой логикой.

## 🖥️ Платформы

Все уроки создаются с учётом возможности запуска на:

* 🐧 Linux

* 🎮 PlayStation 2

Идея курса — использовать максимально общий код, чтобы один проект можно было собирать под разные платформы.

## 🛠️ Требования

Для Linux:

* GCC или Clang
* SDL2
* SDL2_image
* SDL2_ttf
* Make

Для PlayStation 2:

* PS2DEV
* PS2SDK
* соответствующие SDL2-порты и библиотеки

Конкретные требования и инструкции по сборке находятся в соответствующих уроках.
